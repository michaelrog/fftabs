# Other projects in this space...

### https://github.com/dkaslovsky/tabgrab

Essentially what I want; but, doesn't support Firefox.

### https://omar.website/tabfs/

Mounts your browser tabs as a filesystem. Very cool. Overkill for my purposes.

### https://github.com/doctorcolossus/tab_wrangler

TUI for browser tabaholics & tab-hoarders, with vim-like keybindings.

### https://github.com/balta2ar/brotab

Control your browser's tabs from the command line

### https://github.com/erikcw/firefox-tabs

List your open Firefox tabs. Uses an older method: reading Firefox’s session file directly from the profile folder — Which in most cases would provide slightly stale info.
